# Question: Create a Faulty Calculator Using JavaScript

Create a **faulty calculator** using JavaScript.

### Requirements:

1. It takes two numbers as input from the user.
2. It performs the wrong operations as follows:

| Actual Operator | Faulty Operation |
|---|---|
| `+` | `-` |
| `*` | `+` |
| `-` | `/` |
| `/` | `**` |

3. The calculator performs the wrong operation **10% of the time**.
4. The calculator performs the correct operation **90% of the time**.
